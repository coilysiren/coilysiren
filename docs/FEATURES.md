## Profile landing page

- **GitHub profile README** at [README.md](../README.md), rendered as the landing page on <https://github.com/coilysiren>. Deliberately long-form: this repo is exempt from the fleet size caps, so the README is the one place that carries everything inline. **Mobile first**: no layout wider than 2 columns, code blocks stay under ~44 chars.
- **Story-first ordering** (since 2026-06-12): hook then receipts. `lights_out` (the dark-factory thesis) sits directly after `whoami`, `production_floor` (the pretty part) follows it, then `shift_report` and the `tailnet` receipts. The `tailnet` section opens with "Everything above is claims. From here down, receipts."
- **Hero block**: narrow faux SSH banner (MOTD only), lights-out platform framing. `whoami` carries Kai's avatar (hotlinked `github.com/coilysiren.png`, right-floated). The `platform.target` status line carries real fleet numbers (devices, pods, ✗ count) that update with the readout paste; only the systemd unit itself is aspirational (the FAQ says so). `shift_report` is deduped against the banner and `whoami` - role / employer / shift / fleet / specialties / prior_art, no repeated operator or location.
- **`tailnet` section**: two-site fleet tree, per-node hardware inventory (2-column table), live `tailscale status` and `kubectl get pods -A` readouts generated by [scripts/fleet-readout.sh](../scripts/fleet-readout.sh) (hostnames real, opaque ids and third-party devices redacted), local-LLM mode map.
- **`production_floor` four-bay table**: a 2-column HTML table, one row per bay (`coilyco-flight-deck`, `coilyco-bridge`, `coilyco-gaming`, `coilysiren`), each with its logo at 96px and a prose description that weaves the bay's builds in with inline status badges (gauntlet, repo-recall, session-lattice + luca, infrastructure, galaxy-gen, coily, eco-cycle-prep, eco-app, eco-mods). Prose cells, not flat repo lists - that was the 2026-06-12 redesign brief. Curation rules: archived repos are not listed (claude-code-pulse dropped), and the Eco story lives in the gaming bay's consolidated repos (eco-app, eco-mods), not the pre-consolidation eco repos they superseded (eco-cycle-prep stays - it was not part of the merge). This table absorbed and replaced the flat per-repo markdown table on 2026-06-12. The org logos hotlink via `github.com/<org>.png`; the coilysiren bay uses the committed [assets/coily-siren.png](../assets/coily-siren.png) because the account avatar is Kai's headshot, not the logo (canonical source: `coilysiren/website` `src/images/icons/coily-siren.png`). The intro keeps the directed next click: gauntlet and coily as starting points, plus the live demo at [galaxy-gen.coilysiren.me](https://galaxy-gen.coilysiren.me). [production_floor.md](production_floor.md) is a pointer.
- **`lights_out` section**: the dark-factory story (coily security boundary, gauntlet adversarial verification, repo-recall / session-lattice / otel-a2a-relay observability substrate). Positioned directly after `whoami` so the thesis lands before the inventory.
- **`service_history` block**: pre-formatted career timeline, narrowed for mobile, pointing at [coilysiren.me/resume](https://coilysiren.me/resume) and [coilysiren.me/now](https://coilysiren.me/now). Inline in the README since 2026-06-12; [service_history.md](service_history.md) is a pointer.

## Readout tooling

- **[scripts/fleet-readout.sh](../scripts/fleet-readout.sh)**: regenerates the README's `tailscale status` and `kubectl get pods -A` blocks from the live tailnet and cluster, ≤44 chars wide, with the PII rules built in (tailnet IPs / FQDNs / account labels / public IPs never emitted, third-party devices excluded, pod hash suffixes stripped). Routes through coily. Node count is computed live (`ready/total` when they differ); the site count is the one hand-maintained constant (`SITES`, top of script). Carries the kubectl `kai-server.local` + skip-tls-verify workaround inline, tracked for removal in [infrastructure#303](https://forgejo.coilysiren.me/coilyco-flight-deck/infrastructure/issues/303).
